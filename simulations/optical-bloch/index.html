Model and conventions

The basis is |e⟩, |g⟩, with z = Pₑ − Pᵍ and ρₑᵍ = (x − iy)/2. The ground state is the south pole. Δ = ω₀ − ωdrive; Ω is a real drive along x. The rotating-wave and Markov approximations are used, with relaxation to the ground state.

The pulse duration is π/Ω or π/(2Ω), defined on resonance. Spin echo uses one refocusing π pulse halfway through the free evolution. For N π pulses, the total free time τ is divided into N equal intervals: the first and last delays are τ/(2N), with τ/N between π pulses. All pulses use the same phase and have finite duration π/Ω. The scan varies τ and holds the pulses and all other parameters fixed. Echo pulses refocus the static detuning distribution; memoryless Markovian dephasing is not reversed. Detuning also acts during finite-duration pulses, so refocusing may be imperfect. The dashed vertical line in each time plot marks the current playback time. Numerical curves use fourth-order Runge–Kutta integration.

Quantum trajectories

The pink vector is the density-matrix expectation value. Each gold vector is one possible conditional pure-state trajectory for an idealized monitoring scheme; it stays on the surface. Different environmental measurements can produce different valid trajectories, so it is not a unique account of what an unobserved qubit “really does.” Averaging many trajectories recovers the density matrix.

We use quantum jumps with emission operator L1=Γ1σ− and phase-flip operator Lφ=Γφ/2σz. Pure dephasing can be represented by random phase flips or by continuous Gaussian phase diffusion with variance 2Γφ dt; both recover the same Markovian ensemble dephasing. Neither representation is a uniquely prescribed microscopic history. Between jumps, the state evolves under the normalized no-jump dynamics. A mixed initial state is sampled as ground or excited with equal probability. Restart generates a new swarm. The pink vector is calculated independently from the Bloch equations; a finite swarm only approximates it. For Ramsey and echo sequences, σΔ sets the standard deviation of a Gaussian distribution of static detunings. Each trajectory keeps its own detuning throughout the experiment; the pink vector and scan average over that distribution. Set σΔ = 0 to remove inhomogeneous broadening.
